# Rank-seven massless arrays and shared execution

The priority remains a complete independently validated implementation through
rank seven. The objective is open. Low-rank COLLIER speed and interpreter/native
selection are not completion gates.

## Complete massless arrays

The [massless capsule](../../validation/public-rank7-massless-ir/README.md)
contains three original quad-IBP references and six Float128/256 PV arrays for
a lightlike scaleless bubble, an on-shell triangle and a scattering box. Every
cumulative moment through rank seven and every native Laurent coefficient is
retained. All 7,920 reference comparisons, 3,960 precision pairs and four reused
scalar checks pass. Maximum normalized reference error is approximately
`2.522e-16`; the precision-pair maximum is approximately `5.891e-37`.

The UV and IR single poles of the scaleless bubble remain separately nonzero.
All six Rust calls use analytic PV and no fallback. The comparison never applies
positive-mass IR-zero identities to massless data or projects small coefficients
to zero. The independent numerical review reconstructs all 11,884 checks.

This is a qualification of the retained frozen actual-Cargo artifact and exact
point set. It is not a later-main rebuild, general massless-domain, generalized,
Dual or performance qualification. The controller did not save absolute UTC
start/finish times: phase ordering and maximum concurrency are executor-attested.
Per-case terminal evidence passes. Diagnostic durations are not kernel timings.

## Shared core facade

The [facade capsule](../../validation/shared-tensor-facade/README.md) qualifies
the additive `TensorReductionPlan` / `TensorWorkspace` interfaces. Generic and
eligible ordinary PV six-/seven-point execution share settings validation and
the existing Symbolica contraction API. The facade preserves the requested
algorithm, compiled default master policy and explicit capabilities. Dual,
profiling and nondefault-policy requests use the generic path; it does not
silently reinterpret those requests as thin PV.

Six ordinary tests and one separately selected actual numerical test pass. The
latter compares Float128 N6/N7 scalar delegation with existing public wrappers,
including invalid neighbors, common contractions, input preservation, nested
child/parent/certificate work counters and empty-call reset. The initial
test-only trait-import compilation failure is retained. No new recurrence,
symbolic algebra engine or scalar-master formula is introduced.

These core tests have their own captured source context. They do not establish
CLI/Python integration or every later joint source edit. Frontend builds and
numerical checks are tracked separately.

## Incomplete method coverage remains visible

The separate [IBP capsule](../../validation/public-rank7-ibp-owned-artifact-n1-n3/README.md)
retains six attempted rank-seven captures. N1 and N3 finish at both precisions,
passing 15,840 reference comparisons, 7,920 precision pairs and 5,280 scaling
identities. Both N2 captures stop during workspace preparation without an array.
The whole corpus is incomplete. Initial process-cleanup failures and subsequent
absence observations remain distinct records; no performance or complete-method
claim follows from partial success.

Public seven-point tensors, broader method and kinematic families, generalized
rank-seven tensors, supplied-invariant high-point tensors, f64/DoubleFloat and
mixed/higher Dual qualification remain substantive work. Shared frontend
execution must also pass its actual CLI and fresh-wheel checks before promotion.
