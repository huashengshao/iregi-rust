## Reproduction

From the repository root, use `python3 -B validation/<capsule>/check.py` for each
named saved-data capsule. These commands need committed parent capsules and run
no compiler, integral evaluator or network access. The N2 checker uses its
sibling portable module and should use normal Python invocation, not isolated
`-I` mode.

Build the report with `bash scripts/build-benchmark-report.sh`; it fixes PDF
creation time to 1792886400 from the report date. `python3 -B
scripts/check-benchmark-report.py --preserve-from <preceding-report-commit>`
checks artifact/source bindings and byte-preserved historical result values.
The fresh PDF has five added coverage pages near the front. Independent final
rebuild/render verification is recorded separately by the parent before push.
