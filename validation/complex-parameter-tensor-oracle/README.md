# Complex parameter tensor oracle: saved evidence

This capsule preserves an independently audited numerical parameter oracle for
ordinary N2/N3/N4 tensor integrals at one fixed lower-half-plane complex-mass
fixture per topology. Each result contains all330 cumulative raw Cartesian
moments through rank7 and four separate native UV1,IR1,IR2,finite slots. The
first210 moments form the exact cumulative rank6 prefix. No incomplete result
is replaced by a successful zero.

All18 fixed grids completed: orders12/20/32, identity/reversed simplex maps,
N4 first then N2 and N3. There are88,256 evaluated rows and23,760 saved complex
Laurent slots. The unchanged independent saved-data checker reproduces its
**entire original receipt**, including43,566 comparison records,11,880 separate
IR-zero checks and15 negative controls. All pass. The comparison records are

(+---), shifts given by the prefix of `0,e_x,e_y,e_z`, and squared masses
`k-i*k/8`, k=1..N. Their Feynman polynomial has Re(F)>=1 and negative imaginary
part. There are no IR-singular, timelike threshold or cut fixtures here.
Symbolica's built-in Gamma Laurent expansion, source polynomial extraction and
derivatives supply all algebra. Native i*pi^2 and the dimensionally regulated
scale factor are included exactly once in the worker. Numerical normalization
divides each moment's four slots by the exact unit `3^(degree+4-2N)`.

worker values as separate longdouble real/imaginary sums. Every grid retains
native and normalized arrays, absolute weighted sums, observed integrand and F
