## Reproduction

With this capsule and its committed parent capsules in a checkout:

```
python validation/rank7-numeric-jets/check.py
python validation/rank7-numeric-jets/check.py --reconstruct target/n2-source-roundtrip
```

A relocated copy can use `--parents-root /path/to/checkout`; no original
/shared/external/iregi/iregi-rust/targetpath is required. Source export writes
separate build-001/build-002trees. It never compiles or runs them. Run the checker
under the separately reviewed finite data supervisor; it starts no subprocess.

Tooling is prepared in target/rank7-numeric-jets-capsule-v1. `package.py --draft
DEST` creates an explicitly unsealed draft in a fresh direct child of project
target, outside the scanned input corpus. New source/text evidence rejects native
suffixes and ELF/ar/gzip/zip/PEsignatures before full reading or hashing. Committed
parent archives remain inherited. Final sealing requires the parent's
exact release binding that reviewed draft manifest, all six code files, both
independent audits, the exact frozen a5bc mutation companion and source/data
verification evidence. The final release and
its additional evidence are copied into the deduplicated payload. Intermediate
failure receipts remain outside the immutable capsule until explicitly included.
No source preparation or sealing step executes an integral, evaluator or compiler.
