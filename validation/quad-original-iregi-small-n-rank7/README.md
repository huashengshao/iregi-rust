# Original quadruple small-N rank-seven reference corpus

This package preserves **reference generation and applicable identity checks**, with explicit original-PV failures. The fixed cohort requested N1–N4 at rank seven for three exact conditioned samples in both IBP and PV modes, plus two N5 IBP sample controls. An already archived N5 base completes a 15-array, three-sample N1–N5 IBP reference corpus. No Rust output was evaluated or compared by this cohort.

All 26 native processes exited, but only **23 arrays / 30,360 complex Laurent slots** were complete. The three N2 PV calls printed `ERROR:out of range of pave_UV` and no RESULT: **3,960 slots remain missing**, never successful zeros. Their stderr, stdout and successful transport exit codes remain visible. The unchanged source-capacity observation is preserved separately from numerical evidence.

The 14 new IBP arrays pass native stability and their applicable independent identity controls. With the inherited N5 base they supply **15 arrays / 19,800 complex slots**. All 6,600 IBP scaling comparisons pass; positive-F IR, convergent-degree UV and origin-tadpole parity checks also pass. These identities do not independently certify every finite coefficient or achieve a claimed 33-digit accuracy. Original constants, stopping criteria, formulas and thresholds remain unchanged.

Only the three N1 PV arrays agree with eligible same-input IBP controls. Six N3/N4 PV arrays report stable native results but fail in **486 finite slots**: 71 for each N3 sample and 91 for each N4 sample. Those arrays remain rejected diagnostics. Kind promotion, successful process exit, and a native stable flag do not override missing responses or full-array disagreements. No mode is silently substituted.

The saved validator has **42,018 exact numerical records**. Each moment uses its own degree `r`, squared natural unit `(Q²)^(r+4−2N)`, exact `Fraction` gates at squared threshold `1e-20`, and decimal display only. IR residues vanish for all positive-F cases. UV zero is required only for negative superficial degree; higher-degree UV coefficients remain intact. Any odd Cartesian exponent in origin-routed N1 gives a symmetry-zero component. The scale control changes momenta by 2, squared masses by 4, and scale μ by 2, requiring every Laurent slot to scale by `2^(r+4−2N)`. Scaling eligibility requires both partners to pass native and applicable identity controls. The archived N5 base is additionally checked at 660 IR and 126 convergent-UV slots. The mass-plus-one input is not derivative evidence.

The capsule borrows the hash-pinned positive-rank companion (`6fbc3465…`) and N6 adjudication (`7c27b1…`), including canonical original source, full complex-matrix implementation, precision canaries, upstream OneLOop COPYING, old failed builds and N6/positive-rank saved proofs. It does not duplicate that wide closure. Own files include all 24 original small-N requests and their fixture/source-freeze, two new N5 requests, the unexecuted initial proposal, review corrections, parser-only negative-control receipt, all raw streams/worker logs, source/independent reviews, grant, diagnostics, release and final scoped qualification. ```sh
python validation/quad-original-iregi-small-n-rank7/check.py

The destination must not exist. Only the hash-pinned independent parent checkers are imported. No producer comparator, native executable, compiler, integral evaluator or process probe runs. Available archived source/data hashes are checked afresh; omitted native/toolchain digests and historical group absence remain attestations. The copied native binary and Python caches are excluded. The literal Symbolica license value is excluded; upstream source licensing remains inherited.
