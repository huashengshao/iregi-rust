# Final rank-six wheel smoke: saved evidence

This capsule binds a fresh installed PyO3 wheel to the final selected 204 source
bodies, including all 128 bodies from the coherent core build. It records exactly
ten existing API smoke cases: owner-class import identities, three numeric types,
batch isolation and empty batches, dotted mass differentiation, precision beyond
binary64, mixed Dual components, checked scalar-product certification, and the
six-point rank-one dispatch/contraction/recovery case. The rank-six native
mathematical qualification remains separate from this frontend smoke.

The six bounded stages are build, install, import, eight ordinary API cases, one
checked Dual case, and one six-point case. Their seven owned process groups all
terminated successfully. The source freeze, actual commands, all stage logs and
receipts, exact XML test IDs, recorded wheel/native identities, and the frozen
controller are retained. All ten cases must pass; skipped or failed cases fail
the checker.

The checker uses only Python's standard library. It reads saved records and
selected text source bodies directly from this capsule and named, hash-bound
existing source archives. It never invokes another capsule's checker, imports the
native extension, compiles, evaluates an integral, or probes a process. Compiler,
native hash, installation, and process-ownership claims are historical producer
observations. The wheel and native ELF are intentionally omitted. The installed
native hash equality and owner-class identity assertions are bound to the frozen
controller and successful import receipt; the checker does not recompute an
omitted native binary's hash.

This is a final-source frontend smoke check. It does not repeat wheel004's 65 API
and seven notebook cases or its static typing check, and it does not add an
independent numerical integral, high-point acceptance, performance qualification,
or a complete hermetic compiler/native/system dependency closure.
