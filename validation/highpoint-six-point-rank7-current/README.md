# Current-Cargo six-point rank seven

The public `SixPointReductionPlan` now accepts ranks zero through seven. The
change expands its guard and example, without changing the existing thin
recurrence, scalar masters or ordinary/Hybrid dispatch.

The actual locked/offline Cargo build passes, as do both public domain tests.
On the retained real-mass point, all 330 moments and 1,320 complex native Laurent
slots at each of Float128 and Float256 agree with independently built original
IREGI quad-arithmetic IBP. The maximum normalized difference is about
`1.27e-16` at the unchanged `1e-10` gate. All 1,320 precision pairs pass `2^-80`.
Each capture evaluates all six five-point subsets in one packed child batch.

The original source formulas, limited-digit constants and stopping criteria
remain unchanged. Promoted arithmetic does not establish 113-bit physical
accuracy. Original binary64 IBP's 90 failures remain in the earlier evidence;
original quad PV and Hybrid remain unqualified on this point. The quad-source
and raw numerical audit is copied here; the separate quad-reference capsule
records its full build provenance.

The source archive contains all 92 project files frozen for this Cargo build.
`binary.json` records the actual Cargo artifact and its copied executable hash;
compiled products are not distributed here. The complete dependency/build
context remains in the repository lockfile and earlier dependency provenance.
`compare.py` retains the original live-tree saved comparator and its independent
source review. `check.py` replays the saved gates portably:

```sh
source scripts/env.sh
python3 -B validation/highpoint-six-point-rank7-current/check.py
```

This singleton family does not qualify full lifecycle/contraction behavior,
literal rank-four/five/six plans, other numeric types, Dual, complex masses,
generalized powers/shifts, exceptional kinematics or performance. These remain
separate work. Stage durations are validation diagnostics.
