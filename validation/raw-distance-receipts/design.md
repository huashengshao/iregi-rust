# Raw-distance proof receipts: private experiment

This experiment reuses only exact Zero certificates for selected raw-distance polynomial Taylor components. It does not reuse numerical argument outputs, conditioning decisions, snapped invariants, Gram chart certificates, scalar masters, or output values. Production is unchanged.

## Identity and lifetime

The immutable domain stores the ordered Symbolica parameter Atoms, ordered original-input distance polynomial Atoms, lexicographic propagator pairs, complete InputLayout, invariant authority, full ordered Dual shape, and InputPolicy. Structural Atom equality establishes identical expressions; no floating equality, approximate comparison, custom polynomial normalization, or sample hash is used. Reuse is initially restricted to Preserve. The same generic numeric type, prototype precision, and requested accuracy are required.

A call-local receipt borrows its original KinematicsBatch and contains exact proven (constraint, Taylor-component) masks indexed by original local row. Analytic dispatch verifies source object identity, copies source rows using its existing loop, and passes an incoming receipt view plus the explicit source-row indices to a private reduction entry. Compacted rows map through valid_lanes and then the incoming source-row map. A child creates a fresh receipt borrowing its own local batch. No receipt survives the call or resides in Workspace; clones and subsequent calls cannot inherit proofs. Hybrid retries and precision rescue enter through the public no-receipt path.

## Child work retained

Every child runs input validation, its snapping diagnostics, the complete argument evaluator, the positive conditioning envelope, and every nonzero/zero conditioning check. Only after those checks does it form its own computed-zero selection. Covered selected pairs are removed from the exact-certificate request. All uncovered pairs use the unchanged exact conversion and full-Taylor real/complex classifier. A row with no uncovered selected pairs needs no second ball evaluation. A partial mask still executes the certificate's full DAG; no arithmetic pruning is claimed. Only actual nonempty selections returning exact Zero create coverage. Nonzero/Unresolved certificates and empty-selection Zero do not create blanket receipts.

argument_rows remains unchanged, including the observed ggH parent+child count of two. Private counters will distinguish certificate rows/passes and covered pairs; these are diagnostic work counts, not timings or a public API proposal.

## Required qualification

Compare complete outputs, represented precision, signed zeros, statuses, flags, diagnostics and ordinary work counts against the identical slim-RealBall baseline. Cover ordinary and mixed/reordered Dual shapes, real/complex Taylor products, partial/new selections, supplied-G authority, invalid/unstable compaction and row permutations, failed optional profile rejoin, multiple calls and clones, changed prototype/requested accuracy, and Legacy policy nonreuse. Retain existing rounded-zero and nonzero cancellation rejection tests. Instrument selected masks to establish that actual proof work is saved; argument_rows alone is not evidence.

The slim RealBall baseline is independently under qualification. Builds must wait for a coherent frozen dependency closure; no timing is authorized yet.
