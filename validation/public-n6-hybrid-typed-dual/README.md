# Public N6 rank-six default Hybrid and typed mixed Dual evidence

This capsule extends the immutable [explicit-PV capsule](../public-n6-affine-mixed-dual/README.md).
It preserves two distinct successful domains and a real, unqualified binary64
guard outcome. No parent capsule or original failed receipt is modified.

## Default Hybrid Float128/256

The public constructor's unchanged Hybrid default passes both complete mixed
Float precision captures for the fixed real massive N6/rank-six, unit-power,
h=0 family. The six ordered Taylor components are
`[(0,0),(1,0),(0,1),(2,0),(1,1),(0,2)]`, with first squared-mass and dilation
axes. Both raw captures explicitly record `public_default` algorithm origin;
the actual child methods, preparation notes and counters remain available.
Requested Hybrid is not presented as pure IBP.

All **30,240 parent complex comparisons** against the admitted original-quad
unit/dot/triple responses pass `1e-10`, maximum approximately `3.07559e-15`.
All **75,600 Float128/256 pairs**, including **60,480 actual child pairs**, pass
`2^-80`, maximum approximately `5.47562e-30`. At each precision, fifteen full
parent/child sensitivity contexts and twelve actual N5 child rows are checked.
Every child explicitly reports `KnownNoQuadrature`; that origin is never
inferred from its zero error array. The three-lane repeated/invalid schedule,
empty reset, singleton recovery, input preservation and context coupling are
verified. Sensitivity amplitudes remain heuristic; unsupported propagated
quadrature contexts are not qualified.

## DoubleFloat and preserved f64 guard

The release example packages existing Symbolica static/dynamic Dual values into
the public component-major kinematics interface. It does not introduce or claim
a typed convenience constructor. The DoubleFloat mixed case retains 106-bit
representation metadata and returns all 210 moments, four native Laurent slots
and six components for three valid rows across static and dynamic calls.

All **15,120 original-quad comparisons**, **15,120 qualified public Float128
controls** and **5,040 scale identities** pass. Original/scale tolerance is
`1e-10`; the Float128 control tolerance is `2^-80`. Their maximum normalized
errors are approximately `3.07559e-15`, `1.96691e-25` and `8.03765e-26`.
Static and dynamic base outputs match exactly, the invalid-mu neighbor has no
array, and empty state resets.

The corrected f64 case remains **numerically unqualified**. Its three otherwise
valid rows hit the actual `pv_node_12`, Taylor-component-two cancellation guard
and return null arrays. The saved metadata audit passes with zero numerical
comparisons and no claimed numerical disagreement. Those missing coefficients
cannot count as successful zeros.

The initial example invocation failed before reduction because a helper rejected
the six-point ordinary-input dimensions. Its original failed receipt and
`calls=[]` capture remain. The narrow input-preparation correction and both
actual 120-source build contexts are retained separately. This initial refusal
is not relabeled as a precision guard or an accuracy failure.

## Portable replay and source scope

Run from any directory with Python's standard library:

```sh
python3 -I -S -B validation/public-n6-hybrid-typed-dual/check.py
```

The checker reconstructs the pinned PV parent, reuses byte-identical source/data
aliases, and retains only distinct frozen bytes. It validates all actual
build/capture guards, source snapshots, artifact associations and the 34-file
typed evidence index. The Hybrid observer has 119 selected build-source files;
each typed-example build has 120. Executables are omitted and are represented
by historical recorded identities rather than freshly read binaries.

It then reruns the exact independently authored saved-arithmetic functions for
the complete Hybrid pair, DoubleFloat and f64 metadata case, reproducing their
entire saved reports apart from wrapper bookkeeping. The PV parent
supplies the already qualified control arrays and source/reference closure.
`restore_files(manifest)` provides immutable project-relative byte aliases for
later capsules. A minimal validation-only checkout requires only the declared
parent files and this capsule; no external target tree or license is needed.

These are selected source snapshots, not a complete compiler/dependency/system
closure. Pair agreement is not a rigorous achieved-precision bound. The specified
directions, real unit-power h=0 geometry, and explicitly observed routes do not
qualify arbitrary derivatives or kinematics, explicit dotted/D6 parent arrays,
all f64 mixed-Dual inputs, physical amplitudes, rescue, finite differences or the
complete feature objective. No native evaluation, new build or performance
measurement is performed by this replay.
