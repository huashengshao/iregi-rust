# C0/D0 mass-derivative qualification

**Passed for the two fixed massive spacelike cases in `inputs.json`, using installed wheel004.** The public Python API drives the Rust `ReductionPlan`/`Workspace` implementation with six Symbolica Taylor components `[00,10,01,20,11,02]` in two squared-mass directions. The base integral uses hybrid reduction; separately prepared raised-power integrals use IBP. Working precision is 128 and 256 bits, both requesting 53 accuracy bits. Every UV-single, IR-single, IR-double, and finite coefficient is compared at the unchanged dimensionally normalized tolerance `1e-10`.

Each family uses one fixed sample lane. All three pole slots were independently required to be exactly zero, as appropriate for these massive finite integrals; finite values were compared as full complex numbers. No evaluation used fallback or the analytic rescue path. The independent saved-data gates performed 9,238 checks in total, including exact-ratio crosslinks, general complex residual arithmetic, provenance, complete comparison inventories, and process cleanup. Full numeric values are retained as integer ratios, without a Python binary64 round trip.

`qualification.json` is the machine-readable summary. `attempt001/C0/` and `attempt001/D0/` contain original runtime logs, results, process terminals, capture records, independent gate sources, and gate receipts. Both supervisor processes exited zero; all 21 guards matched before and after each run, and owned process groups were independently absent. The recorded wall times, 30.294s and 61.871s, include preparation and provenance work and are **not performance benchmarks**.
