# Current Cargo native-policy qualification

The integrated 17-file native-policy composition passes actual locked/offline
Cargo builds, all 26 selected exact tests and two public five-lane N3/rank1 probes.
Default and explicit Symbolica records are exact; all 400 original-IREGI complex
tensor comparisons and 80 selected-vs-Symbolica comparisons pass the unchanged
dimensionally normalized 1e-10 gate. The invalid-scale lane, all four Laurent
slots, complete basis/metadata/diagnostics, input bits, repeats and batch counters
remain explicit. Unit assertions cover ordinary DD/Float/static+dynamic Dual
carriers, precision guards and selective native type/family exclusions.

The full metadata feature matrix did not pass. Default and native-f64-abc checks
passed; broad legacy hit its fixed 240s frontend cap and the both-feature case
remained unrun. The failed matrix and raw logs are retained unchanged. A separate
root-authorized, independently reviewed admission used exactly the two successful
native-only metadata cases for the original bounded builds. There was no retry,
cap extension, broad/both code generation or weakened numerical gate.

Builds used the normal locked 568-package cache, CPUs 20/21, two jobs, unchanged profiles
and no supplemental externs/RUSTFLAGS. Runtime used CPU 20. Exact executable paths,
features, profiles and hashes came from matching Cargo compiler-artifact records.
Owned copies preserve the default example after Cargo replaced its common path.
Every owned group was closed. Durations are lifecycle diagnostics, not benchmarks.

The archive contains frozen commands/helpers, complete raw logs, output arrays,
receipts, product identities and independent saved audits. It inherits 85 exact
production files from the existing composition capsule and includes the new API
example. All 399 live source hashes and pinned tools are recorded. Three existing
GMP/MPFR/MPC archives were guarded before/after execution; this does not claim a
complete transitive native build-input closure. No binaries, archives of compiled
code or license values are committed. Existing historical capsules stay unchanged.

Verify saved data without a compiler, license or numerical evaluator:

```sh
source scripts/env.sh
python3 validation/native-f64-sixpoint-current-cargo/check.py
```

Use `--origins` while the private saved inputs remain available. The checker
rehashes all payloads, reconstructs the 85 inherited source files and reruns the
reviewed saved-output numerical admission with the pinned benchmark comparison.
Independent raw-number and command/provenance audits are also preserved.

Fresh execution requires restoring the inherited native-only source and archived
example into an isolated checkout, regenerating location-bound freezes and new
exclusive attempt directories, then following commands-and-selection.json.
The original attempts are immutable and must not be resumed or overwritten.
This capsule adds no performance, full legacy feature, N6/N7 numerical, generalized
or high-point derivative qualification. CLI/Python runtime is outside its scope.
