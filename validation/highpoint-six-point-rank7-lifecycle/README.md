# Public SixPoint rank-seven lifecycle and numerator qualification

Run `python3 validation/highpoint-six-point-rank7-lifecycle/check.py` from the
project directory. This verifies hashed source/evidence bindings and replays
the frozen saved numerical comparator in memory. It starts no compiler,
Symbolica evaluator, scalar master or integral. The original independent audit
scripts and receipts are preserved with their exact checksums.

The actual locked/offline Cargo build used checkpoint
`0ce5bf0653a5b2c6d0460bbfe2a5f688cd0558e0` plus the new example
`crates/iregi-rust/examples/six_point_lifecycle.rs`. The93 captured files are
exactly the92 inherited from `../highpoint-six-point-rank7-current/sources.tar.gz`
plus that example. All original source bytes are available without duplicating
the large generated scalar programs. The captured context is distinct from
later generalized-Cayley implementation changes; this is not a blanket claim
about subsequent source revisions or a complete dependency/environment closure.
The root Cargo manifest/lock were captured; individual crate manifests were not
part of this historical93-file inventory. The actual Cargo JSON executable
artifact, root release, immutable snapshots, original command and output hash
are retained. Compiled binaries are deliberately omitted; original independent
audits verified their bytes and process-group cleanup on the execution host.

One ordinary Symbolica Float128 and one Float256 run used a single N6rank7 PV
plan, one prepared workspace, one cloned workspace with independent scratch,
and two prepared Symbolica numerator contractions. Requested accuracy was53bits;
stored component precision and signed zeros are retained individually. The
fixed real-mass fixture has base and uniformly scaled-by-two rows plus an
explicit mu=0 rejection control. It has unit powers, h=0, preserved Cartesian
shifts, native IREGI normalization and raw unweighted tensor components.

Each run completed odd mixed and reordered batches, chunks, empty/invalid-only
calls, cloned scratch, a malformed-buffer probe clearing nonzero counters,
and valid recovery: nine complete result calls plus one malformed API call.
Both sparse odd/mixed support and all330 nonzero dense complex coefficients
were contracted through the library's existing Symbolica batch evaluator.
All successful arrays contain330 moments times four native Laurent slots.
All failure lanes remain inaccessible. Input values, actual precisions, signed
zeros, route flags, diagnostics, and all nested counters are retained.

The initial saved-comparison wrapper had a Python parse typo before any

This evidence qualifies the retained ordinary N6rank7 family and its cumulative
rank0..7 moments, batches and these contractions. It does not newly qualify
separately requested lower-rank plans, other topologies/kinematics, singular
charts, complex masses, generalized powers/dimension shifts, other numeric
types, public Dual behavior or physical numerators. The whole implementation
goal remains incomplete.
