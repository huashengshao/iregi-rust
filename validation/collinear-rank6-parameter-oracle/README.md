# Scoped collinear triangle parameter reference

This capsule preserves an independently replayed parameter-integral reference for one real collinear N3 fixture through rank six. It selects the order-48 identity map after comparing all three order pairs among 20, 32 and 48, for both identity and reverse vertex maps, and comparing the two maps at every order. The unchanged mixed natural-unit tolerance is `1e-10`.

The refined catalogue passes all 15,150 saved records: 7,560 order/map comparisons, 2,520 exact separate IR zeros, 30 convergent UV zeros and 5,040 diagnostic comparisons with the original quad-precision IREGI reference. The largest convergence difference is about `4.172e-14`; the largest original-reference diagnostic difference is about `2.606e-14`. Each independent audit also runs 12 negative controls. The exact decimal components are compared using standard-library rational arithmetic, without importing the producer.

All 330 tensor moments and four native Laurent slots are retained as data, with exact Q=3 dimensional units. Acceptance stops at the first 210 moments, or 840 complex values per grid. There are six refined grids; four order-20/32 outputs are reused byte-for-byte from the earlier capture, and only two order-48 grids were newly evaluated. The latter produced 4,608 rows in 18 batches. The combined refined evidence contains 7,456 rows in 30 batches.

The original order-12/20/32 catalogue remains **failed**, and its 13,470 comparisons are replayed separately. Five order-12/20 comparisons and one order-12 map comparison failed; five original-reference diagnostic disagreements also remain visible. The unexecuted v2 refinement and its two blocking source findings are preserved, together with v3's reviewed corrections and an earlier adjacent-pair draft. No failed result is relabelled.

The portable replay inherits the exact `orthogonal-rank6-current-cli` capsule, which already inherits the complex-parameter oracle and its tested Symbolica worker sources. Original collinear reference outputs and independent admission context are inherited from that parent. Only new small sources, reviews and raw saved evidence enter this payload; identical inherited bytes are borrowed by hash. No native executables, dependency source trees, numerical package trees or license literal are included. Historical binary/package hashes and process-release statements remain saved metadata and are not reenacted.

Run from the project directory:

```sh
source scripts/env.sh
python3 -B validation/collinear-rank6-parameter-oracle/check.py
```

The checker restores immutable aliases in memory and reproduces both entire independent numeric receipts. `--reconstruct /absolute/fresh/directory` writes the restored evidence for inspection. It performs no Git, Cargo, compiler, native process, numerical-package import, symbolic algebra or new integral work. `package.py` deterministically rebuilds this capsule from the original private saved files; it is not required for portable replay.

The portable checkout consists only of this capsule's files plus the exact files listed by its manifest's `parent_files`. A minimal-checkout replay is recorded separately outside the capsule so its inventory remains closed.

This is a fixed-fixture empirical convergence anchor, with no rigorous quadrature error bound. It does not establish TIRust agreement, rank-seven accuracy, other kinematics, arbitrary-precision integral accuracy, integrated Dual derivatives, physical amplitudes or performance. The original quad comparison remains diagnostic. No comparative timing is introduced, and capture durations are correctness-lifecycle metadata only.
