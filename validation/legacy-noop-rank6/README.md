# Retained Legacy no-op N5 rank-six validation

This capsule preserves one complete public CLI validation of the conservative
`LegacyNoOp` admission path. The conditioned, real-mass five-propagator fixture
uses rank six, unit powers, zero dimension shift, explicit PV reduction,
native component weights, and a legacy threshold of `1/1000000`. Every selected
target in the conservative superset of potential original IREGI distance and
PV Gram queries must remain identical in every ordered Taylor component before
the unchanged Preserve child engine is used. The successful point retained
all 51 queries. The requested Legacy policy remains in the public result.

The two saved executions used 128- and 256-bit working components and requested
53-bit accuracy. Each compared all 210 tensor moments and four native Laurent
slots (`UV single`, `IR single`, `IR double`, `finite`) against the first 210
moments of the independently captured original-IREGI kind-16 N5 rank-seven
array: 840 complex comparisons per execution. No rank-six UV slot was projected
away. Maximum normalized differences were approximately `1.09627e-16` in both
comparisons. The two Rust arrays agree within `2^-80` in all 840 complex slots,
with a maximum normalized difference of approximately `2.65877e-32`. This is a
working-precision consistency check, not a claim of achieved 80-, 128-, or
256-bit accuracy. Original reference and Rust algorithm requests differ
(reference IBP, Rust PV); their numerical inputs and native tensor conventions
are bound explicitly by the saved fixture and reference request.

The source context is exactly the 151 files in the successful `build-002`
snapshot. It predates the later generalized supplied-Gram/MassTaylor overlay.
Saved Cargo JSON streams and selected artifact events bind the compiled
library tests, CLI tests, and public CLI identities; binaries are deliberately
omitted. The 26 focused normal test logs are included. Their tests exercise
admission, all Taylor components, lane isolation, thresholds, and legacy
semantics; they do not establish the full public numerical Dual domain.

Failures remain visible: the earlier inline Legacy N5 rank-six attempt aborted
under a 32-GiB address-space bound without arrays; its 256-bit companion was not
run. The first new build failed because `ReductionError` is not `Clone`; the
source before the narrow Arc-cache repair and its compiler log are retained.
The first new 128-bit capture failed its thread-environment preflight before
launching a native job. The explicit-environment v2 controller and both later
successful captures are retained. Historical process identities and absence
receipts are records, not fresh process or binary guards in this checker.

This qualification covers only the retained N5/PV/unit/h0 point. The finite
query superset is conservative: it can reject an unused query that changes
under Legacy snapping. The explicit `generic_plan` API retains the original
Legacy path, including its resource limitations. This capsule does not qualify
the full Legacy domain, changed geometry, N6 full arrays, dotted propagators,
dimension shifts, public Dual or precision rescue, threshold/complex/massless
physical families, performance parity, or timing uncertainty.

Run from the repository root:

```sh
python3 validation/legacy-noop-rank6/check.py
python3 validation/legacy-noop-rank6/check.py --reconstruct /tmp/legacy-noop-saved
```

The portable checker uses only Python's standard library. It verifies the exact
closed payload and declared parent files, reconstructs the 151 compiled source
files, checks historical build/test/capture bindings and failure records, and
recomputes only saved-array numerical error comparisons with exact fractions.
It never imports a producer, compiles code, evaluates an integral, loads a
native library, probes a PID, or reads the live source tree. Reconstruction
writes source/data aliases into a new destination and is not an executable
hermetic build closure. Declared immutable parents are the wheel003 source
manifest/archive, the positive-rank original-IREGI anchor manifest/archive,
and the small-N rank-seven manifest/archive recording that ancestry and the
saved independent N5 base admission. No
license literal, native product, or Python cache is included.
