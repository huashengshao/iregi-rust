This capsule retains the private eight-file implementation of a shared structural
master cache, its isolated build and 18 selected passing tests, and the complete
same-budget typed scalar N6 pilot. It is saved evidence, not production adoption
or a new native build. All four terminal domains remain visible, including the
failed first driver link and both incomplete Dual schedules.

All 88 available slots pass the retained target checks; all 1,736 represented
input slots preserve the exact numeric fixture, including the beyond-53-bit
perturbation. The original pilot's 64 available slots match exactly, including
represented precision and sign metadata. All 24 available paired precision slots
pass `2^-80`; **full precision convergence remains unqualified**, because the
required 240-slot schedules did not finish. Timeouts do not establish mathematical
non-support. Public Dual coverage, derivative uncertainty transport, higher rank,
generalized interfaces, arbitrary independent derivative directions, current
Cargo/full-suite qualification, performance parity and cache speedups remain open.

## Portable check and source reconstruction

Run from the repository root, using only Python's standard library:

```sh
python3 validation/exact-master-variant-cache/check.py
python3 validation/exact-master-variant-cache/check.py --reconstruct target/exact-master-cache-restored
```

The checker validates the exact capsule and borrowed-file inventories, safely
reads regular archive members, and mechanically applies the frozen unified patch.
It reconstructs all 85 base files, all 88 candidate files, all 91 isolated test
build files and all 90 typed capture files. Removing the capture-only module
declaration restores the complete 88-file candidate byte for byte. The optional
reconstruction writes a new directory containing noncompiled evidence and source,
including the original committed typed pilot; no ignored source directory is
needed. There is no compiler invocation, evaluator, integral, reference call,
process launch, or benchmark.

The compact payload reuses the committed
[`native-f64-sixpoint-composition.tar.gz`](../winddown/native-f64-sixpoint-composition.tar.gz)
for its exact base. Eight changed/new files provide the candidate overlay.
Three committed JSON fixtures provide the isolated unit-test include files.
Two already retained capture modules plus an append-only `lib.rs` declaration
produce the typed source. The original pilot is reconstructed through
[`highpoint-six-point-numeric-types`](../highpoint-six-point-numeric-types/README.md).
Generated large master programs are inherited rather than duplicated.

The saved-data checker independently recomputes fixed numerical fixture equalities,
all available target/original comparisons, exact pole zeros, null/failure policy,
operand sign/precision, repeated values, batching/work metadata and available
precision pairs. The fixed coefficient tables come from the independent source
math review. Symbolica performed all original polynomial and Taylor construction;
the portable checker performs only numeric fixture comparisons. Historical audit
scripts are retained as evidence; they are not imported or executed by this
checker, and producer validators are not imported.

## What the implementation and retained tests establish

The shared cache contains exact scalar master programs, keyed by the complete
ordered derivative shape and master execution policy. Plans, lazy variants,
fallback plans and certified charts inherit the same leaf cache while retaining
separate execution caches, numeric buffers, precision, samples and certificates.
Per-family cells publish one result without holding the family map lock while a
factory runs. Factory errors stay local to their key; panics leave the cell
uninitialized; poisoned locks return explicit preparation errors. No plan backlink
is stored in the shared leaf cache.

The selected tests cover real A0 variants and independent roots; ordered shape and
policy separation; concurrent single publication using prebuilt A0 leaves;
failure, panic and poison behavior; independent precision/buffers; inherited
Hybrid, planar and certified charts; empty-batch concurrency and ownership expiry.
Cold Symbolica constructors on worker threads are not qualified by those tests.
The native default bypass remains distinct from explicit Symbolica policy. Whole
E6 policy remains part of its cache key; separate D0 leaves are not claimed to
share internal E6 D0 preparation.

The first direct isolated build passed two products in 60.453835 seconds under a
180-second aggregate bound; 18 exact tests plus listing passed in 24.052863 seconds
under a 300-second bound, both with 20 seconds reserved for cleanup/postguards.
These are lifecycle observations. The retained test receipt, exact names, listing,
18 separate logs, binary digest chain and independent audit are checked. They do
not establish a whole-suite result or optimized performance.

The first typed build compiled its core but failed the driver with `E0460` because
its indirect selected master archive was absent from the driver search closure.
That failure and all unattempted numeric domains remain a separate frozen record.
The reviewed root-authorized continuation reused that exact successful core and
built only the driver, adding the closed selected archive search directory and
explicit master dependency. It passed within the original 90-second build bound.
Each of the four numeric types then had exactly one independent 180-second
attempt and a 20-second cleanup/postguard reserve. No numeric retry, larger budget,
looser tolerance or altered source/inputs was introduced.

## Limits of portable provenance

Nine compiled-product instances and eight generated Python-cache files are
explicitly omitted. Original commands, dependency/tool paths, output digests,
finite-budget receipts, grants and guarded input maps are retained. The portable
checker verifies every guarded byte that it actually reconstructs or borrows from
committed files. It reports unbundled historical guard occurrences separately;
it does **not** access or freshly rehash omitted binaries, `/nix/store`, native
libraries or an ignored build closure. Recorded original/frozen/output digest
chains are checked as saved evidence, not as a new binary attestation.

Likewise, original process-group terminal/absence records and independent audits
are retained. The portable checker never probes historical process identifiers
and does not claim current process absence. Preparation event counts are checked
against all retained original/new logs; nested event durations cannot be summed
or subtracted to infer exclusive costs. `saved-preparation-comparison` and stage
durations are diagnostics only. No performance qualification is present.

`manifest.json` binds the payload, source aliases, exact inventories, borrowed
parents, omission records and scope. `qualification.json` is the unchanged final
typed pilot qualification; `cache-test-qualification.json` is the unchanged
isolated build/test qualification. The independent source, runner, qualification,
saved-value and metadata reviews remain in their original paths inside the
payload. `package.py` documents the one-time deterministic packaging procedure;
sealed capsules refuse in-place resealing. Packaging and checking perform no
native builds or numerical evaluations.
